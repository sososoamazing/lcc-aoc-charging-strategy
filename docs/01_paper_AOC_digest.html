2 研究问题与贡献

2.1 背景

重复脉冲功率负载（X 射线机、静电除尘、加速器、神经科学仪器、高压电容充电电源）中，充电时间占脉冲周期的大部分，脉冲重复率受充电速度限制。LCC 谐振变换器能利用变压器漏感 Lr 和寄生电容 Cp 作谐振元件，在开路/短路下可靠性高，是高压 CCPS 的主流拓扑（PDF p.1，§I）。

2.2 三种传统充电曲线的浪费

策略 早期 末期 能力利用的问题
CC 电流恒定，Im 随 Uo 上升 Im 最大 末期先碰 Imax，前段能力没用足
CP Io ≈ P/Uo 很大 电流下降 初期先碰 Imax，后段能力闲置
HCC–CP 恒流 恒功率 缓解两端极端，但分段折线仍不贴住每个电压点的可行上边界

作者的原话是：这些方法“to some extent improve the charging speed, but they still do not fully use the capacity of the converter”（PDF p.2，§I）。Fig.2 用 CC/CP 的 Io、Im 轨迹说明这一点（PDF p.1）。

2.3 三条贡献（PDF p.2）

  1. 提出基于连续谐振电流的 CRC-FHA 模型，建立不同开关频率下输出电流—电压增益的关系，并可分析电流应力与 ZVS 边界；
  2. 基于 CRC-FHA 提出 AOC：以最大开关电流应力、ZVS 边界、频率上下限为约束，实时生成自适应参考电流，兼顾充电速度与全程 ZVS；
  3. 建成 2174 W LCC 样机，实验显示充电速度提高 12%、全程实现 ZVS。
注意：贡献 3 的“12%”是结论段的取整；§V-B 的原始对比是 1.82 s→1.62 s，速度提高 12.35%。写作时用 12.35% 并注明算法。

3 CRC-FHA：为什么用 ir 而不是 iT

3.1 传统 FHA 的误差来源

传统 FHA 常选变压器电流 iT 的基波。iT 在整流截止区间为零，是不连续波形，含大量谐波；且部分模型忽略 uCp 与 iT 的相位差。用它的基波等效，原波形与基波之间的误差大（PDF p.4–5，§II-B，Fig.9）。

3.2 论文的选择

论文选连续、近似正弦的谐振电流 ir，同时保留 uCp 与 ir 的相位关系，建立 Fig.5 的等效网络。假设：

  • ir(t) = Im sin(ωt)，Im 为峰值；
  • 整流二极管每半周期导通角 θ；
  • 输出电压在若干开关周期内视为不变（准静态）；
  • 主要功率由基波传递；
  • 讨论范围限于 CCM。

3.3 核心变量与关系（PDF p.3–4，式 (2)(10)–(13)）

M  = Uo / (n Uin)                     归一化电压增益
Fn = fs / fr                          归一化开关频率
fr = 1 / (2π√(Lr Cr))                 谐振频率
k  = Cp / Cr                          电容比
ω  = 2π fs
ir(t) = Im sin(ωt)                                        (2)
Io    = Im (1 − cosθ) / (nπ)                              (13)
Im    = 2 ω Cp Uo / [n (1 + cosθ)]                        (12) 的等价形式

θ 由 M、Fn 隐式决定。论文用 k = 0.213 的拟合式 (11) 把 cosθ 写成 M、Fn 的多项式，从而得到：

Io = f(M, Fn),    Im = g(M, Fn)

关键理解：相同 Im 不对应固定 Io；Io 还取决于 θ。θ 又随 Uo、fs 变化。所以“恒流”并不等于“恒应力”，AOC 才有优化空间。

3.4 模型验证

Fig.10 把 CRC-FHA 预测的输出特性与仿真对比，曲线在工作范围内吻合（PDF p.6，§II-B）。这是模型验证，不是全参数域精度证明，也不是器件换流动态验证。

写作提醒：不要写成“CRC-FHA 在整个工作域都精确”。论文只给了所示范围内的对比；k = 0.213 的拟合式也不能外推到其他 k。

4 三条约束与 A 点

4.1 电流应力边界

由式 (13)(14)：

Io = Im (1 − cosθ)/(nπ) < Imax (1 − cosθ)/(nπ)            (14)

把式 (11)(12) 代入，得到关于 M、Fn 的多项式不等式 (15)，其最小可行 Fn 记为 Fnmin1。物理含义：在给定 Uo 下，fs 不能太低，否则 Im 超过 Imax。

4.2 ZVS 边界

论文的 ZVS 判据是输入电抗感性：

Xin = ωLr − 1/(ωCr) + (θ − π − cosθ sinθ)/(πωCp) > 0        (16)

把式 (11) 的 cosθ(M,Fn) 代入，化简为：

kπ(Fn² − 1) + 0.4434 cos3θ − 2.031 cosθ − 1.571 > 0          (17)

其最小可行 Fn 记为 Fnmin2。式 (19) 是式 (17) 代入 cosθ 后的展开多项式（论文给出具体系数），用于数值求解。

边界性质：式 (16) 是作者采用的近似判据。严格的工程 ZVS 还要检查死区内开关节点电容能否完成充放电、门极开通前 Vds 是否接近零。论文用实验波形（Fig.27）支持结论，但不是每个电压点都做了逐点实验。

4.3 频率范围

1 < Fn < fmax / fr        (18)

即 fr < fs < fmax。下限保证 CCM；上限由开关/驱动能力决定。

4.4 A 点：两条边界的交点

Fig.11（PDF p.6）横轴 M、纵轴 Io：

  • 黑色虚线：Imax 允许的输出上限；
  • 蓝色虚线：Xin > 0 的 ZVS 近似边界；
  • 红色轨迹：取两者中较低的输出上限，并受频率上下限限制。

A 点前：电压低、ZVS 余量较大，电流应力边界更紧 → 沿 Imax 边界，Im 接近 Imax。 A 点后：继续沿 Imax 会进入非感性区 → 改沿 ZVS 边界，Io 适当减小，Im 可低于 Imax。

这不是“恒流”也不是“恒功率”，而是逐电压点的约束最优。A 点后 Im 低于额定不等于控制保守，而是另一个约束先起作用。

4.5 式 (20) 的真实含义

Fnmin = min{ fmax/fr , max(Fnmin1, Fnmin2) }        (20)
  • 内层 max：两个下界同时满足，取较大者；A 点前由 Fnmin1 主导，A 点后由 Fnmin2 主导。
  • 外层 min：上限截断。
  • 陷阱：若 max(Fnmin1,Fnmin2) > fmax/fr，外层 min 只给出截断值，被违反的下界约束并没有恢复可行。工程实现必须先判可行区间非空，再处理无解/降额/保护。
  • 还需单独满足式 (18) 的 1 < Fn 和模型适用域。
这一点在组会问答里被单独列为“式 (20) 外层 min 是不是已经保证了全部约束？”答案是否定的。写作时不要写“式 (20) 保证所有约束”。

5 三阶段控制

Fig.12/13/14（PDF p.7）给出控制结构：

阶段 触发 行为 目的
1 预充 Uo < Uref1 固定 fs1，涓流充电到 Uref1 避开零压启动，不让主充电段模型直接用于 Uo≈0
2 AOC Uref1 ≤ Uo < Uref 采样 Uo → M → 解 Fnmin1、Fnmin2 → 式 (20) → 式 (11) 得 cosθ → 式 (13) 得 Iref → 电流 PI → PFM 每个电压点用满可行输出电流
3 恒压 Uo ≥ Uref Burst：停充；漏电跌到 Uref2 再以 fs2 工作若干周期 维持输出电压

控制层次：

  1. 模型算出边界频率 Fnmin；
  2. 由 Fnmin 算 Iref；
  3. Iref 进电流 PI，PI 输出实际频率指令；
  4. 频率指令还要限幅、抗积分饱和、处理可行性。
“模型算出的边界频率”和“PI 最终执行的频率”是不同层次。论文没有把二者混为一谈；写作时也不要写成“模型直接给定开关频率”。

6.2 充电速度（PDF p.11–12，Fig.23）

相同 Imax = 105 A、相同 720 V 目标：

策略 时间
HCC–CP 1.82 s
AOC 1.62 s
  • 论文口径：充电速度提高 12.35% = 1.82/1.62 − 1。
  • 另一口径：充电时间缩短 10.99% = (1.82−1.62)/1.82。
  • 两者都对，但不能混用。写作时建议写“速度提高 12.35%（时间由 1.82 s 降至 1.62 s）”。

Fig.23(b) 显示两策略最大谐振电流限制相同；Fig.23(c)(d) 显示 AOC 的 Io、Po 全程更大。

6.3 热（PDF p.12，Fig.25）

  • ANSYS Icepak 半桥模块热仿真；器件损耗由电路仿真提取。
  • 环境 20 °C；AOC 温升 42.3 °C，HCC–CP 53 °C。
  • 为放大差异，损耗和作用时间都乘了 4（P1/P2/P4/P5/P6 = 104.1/135/139.7/144.1/147.9 W；t0/t1/t2/t3 = 4.346/6.465/6.48/7.28 s）。
  • 因此：这是热仿真，不是实测温升；不能写成“实验测得 AOC 温升低 10.7 °C”。结论段的“10.7 °C”是 53 − 42.3 的取整。

6.4 ZVS（PDF p.13，Fig.27）

  • 作者逻辑：ZVS 在充电末期最难实现；若 720 V 末端能实现，则全程可实现。
  • Fig.27 是 720 V 末端的实验波形。
  • 准确表述：末端实验波形 + 模型边界共同支持“全程 ZVS”的结论；不是每个中间电压都做了逐点实验。
  • 对三相项目：最不利换流事件不一定只在末端，不能预设“末端通过=全程通过”。

7 论文自己承认/隐含的边界

边界 依据 对写作的含义
单相全桥 Fig.1、样机 不能直接迁移到三相 Δ/Y 的耦合与整流模态
k = 0.213 的拟合式 式 (11)(15)(19) 不是所有 LCC 的通式；换参数必须重推
准静态、CCM §II 假设 零压启动、弱阻尼、模态切换要另做时域验证
ZVS 用 Xin > 0 近似 式 (16) 不是实际死区电荷/Coss 的严格认证
热是仿真且损耗×4 §V-C 不能当实测温升或整机效率
ZVS 只展示末端波形 Fig.27 不能写“逐点实验覆盖全部电压”
速度快 ≠ 损耗低 §IV/§V 论文比较的是相同 Imax 下的速度；没有给出全程损耗最优证明
Burst 恒压 §III-D 与本项目“800 V 锁存、不自动重启”不同

8 与文献对比时的正确说法

可以写

  • “Qin 等针对单相 LCC CCPS 提出 AOC，用 CRC-FHA 建立 Io(M,Fn)、Im(M,Fn)，以 Imax、Xin>0、fr<fs<fmax 为约束，在线生成 Iref，经电流 PI 实施。”
  • “在 2174 W 样机上，相同 Imax=105 A、相同 720 V 目标，HCC–CP 用 1.82 s、AOC 用 1.62 s，速度提高 12.35%。”
  • “该文的热结果为 Icepak 仿真（损耗与作用时间×4），ZVS 证据为 720 V 末端实验波形与模型边界。”
  • “AOC 的核心不是恒流/恒功率，而是逐电压点求满足全部约束的最大可行输出电流。”

不能写

  • “AOC 是本文首次提出/本文实现了 AOC。”——AOC 是 Qin 2023 的；本项目只做离线查表迁移。
  • “AOC 保证全局最优/全程 ZVS。”——论文用的是近似边界和末端波形，不是全局证明。
  • “AOC 使效率提高/温升降低 10.7 °C（实测）。”——热是仿真且放大 4 倍。
  • “12.35% 可以直接用于三相。”——对象、参数、模型、时间尺度都不同。
  • “CRC-FHA 在所有 LCC 参数下都准。”——k=0.213 拟合，适用范围有限。

9 与项目的接口

文献要素 项目里怎么用 不能怎么用
“逐电压点最大化可行 Io”的目标 作为 59 节点搜索的目标函数 不能说“因此本文是 AOC”
Imax 边界 换成三相相峰值 14 A 情景 不能把 105 A 直接折算成 14 A
Xin > 0 ZVS 边界 换成逐桥臂换流方向 + 电荷代理 + 残压诊断 不能把单相 Xin 公式套到三相
式 (20) 的 Fnmin 项目不用该解析式；用离散 HOGA 搜索 不能把式 (20) 写成项目控制律
三阶段/Burst 项目只借“预充—主充电—停充”结构；停充是锁存 不能写“实现了 Burst 恒压”
1.82/1.62 s 只作为文献背景 不能与 2.153487 ms 比“快多少倍”

项目最终轨迹的细节见 03_project_AOC_final.md。
