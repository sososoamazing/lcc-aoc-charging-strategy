02 公式、符号与适用域

用途：写论文时直接取用公式与符号；同时标明哪些是文献公式、哪些是本项目定义、哪些不能移植。公式编号：(Q-n) 为 Qin 2023 原文式号；(P-n) 为本项目定义，不与论文式号冲突。

2 文献公式（Qin 2023）

2.1 归一化与谐振

M  = Uo/(n Uin)                                      (Q-10)
Fn = fs/fr                                           (Q-12)
fr = 1/(2π√(LrCr))                                   (Q-12)
k  = Cp/Cr                                           (Q-12)
ω  = 2πfs

2.2 连续谐振电流假设

ir(t) = Im sin(ωt)                                   (Q-2)

含义：谐振电流连续、近似正弦；Im 为峰值。论文选择 ir 而非不连续的 iT 作为 FHA 基准。

2.3 输出电流与峰值电流

Io = Im (1 − cosθ)/(nπ)                              (Q-13)
Im = 2 ω Cp Uo / [n (1 + cosθ)]                      (Q-2 的等价形式)
  • Io 由副边整流电流在半周期内积分得到；
  • Im 由 Cp 的充放电电荷平衡得到；
  • 两式说明 Io、Im 都由 (M, Fn) 通过 θ 决定，不能只看 Im。
注意：式 (Q-2) 在不同版本中可能写作 Cp 电压/电荷形式；上面是论文式 (2) 与 (13) 联立后的常用等价写法。引用时以原文式号为准，不要把它写成“论文原式”。

2.4 导通角拟合

cosθ = P(M, Fn; k = 0.213)                            (Q-11)

论文式 (11) 是 k = 0.213 下的多项式拟合，用于把 cosθ 显式写成 M、Fn 的函数。本文件不转抄系数：一是排版易错，二是它只对该样机参数有效。需要数值复现时回原文 p.7（PDF p.7）取系数。

2.5 电流应力边界

Io = Im (1−cosθ)/(nπ) < Imax (1−cosθ)/(nπ)            (Q-14)

代入 (Q-2)(Q-11)(Q-13) 得：

P_Imax(M, Fn) < Imax                                  (Q-15)

解出最小可行归一化频率 Fnmin1。

2.6 ZVS 边界

Xin = ωLr − 1/(ωCr) + (θ − π − cosθ sinθ)/(πωCp) > 0  (Q-16)
kπ(Fn² − 1) + 0.4434 cos3θ − 2.031 cosθ − 1.571 > 0   (Q-17)

代入 (Q-11) 得 Fnmin2。式 (Q-19) 是 (Q-17) 的展开多项式（论文给出系数）。

适用域：Xin > 0 是“输入阻抗感性”的近似判据；不是死区电荷/Coss 的严格 ZVS 认证。

2.7 频率范围

1 < Fn < fmax/fr                                      (Q-18)

2.8 频率下界合成

Fnmin = min{ fmax/fr , max(Fnmin1, Fnmin2) }          (Q-20)

实现要点：先判 max(Fnmin1,Fnmin2) ≤ fmax/fr 是否成立；不成立时无可行解，不能把截断值当可行解。

2.9 参考电流

Iref = Im(1 − cosθ)/(nπ)                              (Q-13) 回代

流程：Fnmin → 式 (Q-11) 得 cosθ → 式 (Q-13) 得 Iref → 电流 PI。

3 项目公式（最终 59 节点轨迹）

3.1 逐点优化

fs*(Vo) = arg max  Io(Vo, fs)                         (P-1)
          fs ∈ F(Vo)
  • Io(Vo,fs) 是三相共用整流桥的平均输出电流，由 HOGA 冻结 Vo 周期解给出；
  • 不是三个单相电流相加，也不是瞬时电流。

3.2 可行集合

F(Vo) = { fs :
    HOGA 物理守卫通过（电流零和、钳位残差、能量闭合等）,
    阶数验收通过（H31/H63，按点）,
    CCM 分支存在且稳定,
    max_j |io_j| ≤ 14 A,
    min_ℓ i_comm,ℓ ≥ 1.40019 A,
    210 kHz ≤ fs ≤ 340 kHz }                          (P-2)

各项含义：

项 来源 性质
HOGA 守卫 三相 HOGA 周期解 数值/物理必要条件
阶数验收 H31/H63 收敛检查 数值精度门槛
CCM 选定导通分支 模型适用域
14 A 研究情景 不是器件额定
1.40019 A Qreq/teff 必要能力代理，不是 ZVS 认证
210–340 kHz 研究搜索窗口 不是硬件许可

3.3 换流电荷代理

Qreq  ≈ 2 × Qoss(50 V) = 2 × 55.505 nC = 111.010 nC   (P-3)
teff  = 79.281831 ns                                  (P-4)
Icomm,min = Qreq/teff = 1.4001947 A                   (P-5)
  • Qoss(50 V) = 55.505 nC、1.039904 μJ 来自 MOS 手册 19 锚点分段线性积分（IPP70N10S3L-12）；
  • 对称桥臂完整换流需要两只 MOS 的电荷，故乘 2；
  • teff 由 100 ns 命令死区与 14.945 ns RC 门极、2 V 阈值推得；
  • 这个代理只回答“电流在有效窗口内能否提供足够电荷”，不回答“Vds 是否真的到零”。

3.4 准静态充电时间

T20→800 = Co ∫[20,800] dV / Io(V, fs*(V))             (P-6)
t800    = t20 + T20→800                               (P-7)
  • Co = 3.125 μF；
  • t20 = 65.456 μs（共同启动，M2 口径）；
  • 数值积分层级：59 节点分段/Simpson；不要把显示小数位当误差上界；
  • 适用条件：每周期 ΔVo 足够小、轨道可达、Io > 0。

3.5 分段常值频率与连续相位

fs(Vo) = f_k,   V_k ≤ Vo < V_{k+1},  k = 1..59         (P-8)
θ(t)   = ∫ 2π fs(Vo(τ)) dτ                             (P-9)
  • 实现用 1-D 查表（Flat / zero-order hold），区间内不插值；
  • 三相相位由同一积分器产生，频率切换时相位连续，保持 120°；
  • 215–293 V 的 41 个点本身构成一条直线桥，表内已细化；运行时仍按节点查表。

3.6 停充锁存

q[k+1] = q[k] OR (Vo[k] ≥ 800 V)                       (P-10)
GateEnable = 1 − q                                   (P-11)
  • 100 ns 采样；
  • 锁存后封锁六路驱动，模型继续求解，保留残余能量与过冲；
  • 没有电压回落自动重启、预关断补偿或耗能钳位；
  • 重开仿真复位。

3.7 理想开关动态的数值设置

项 值
求解器 ode15s
RelTol / AbsTol 2e-7 / 2e-9
MaxStep 1/(200·299257) s
StopTime 3.5 ms
器件 Ron = 1e-6 Ω、Vf = 0.6 V、Goff = 1e-11 S、td = 0、Coss = 0

这套设置下 t800 = 2.153487 ms。它不是 100 ns 死区 + Coss/Cj 的器件近似模型。

文献 项目 关系
Imax 相峰值 14 A 都是“电流应力上限”，但对象/定义不同：文献是单相谐振峰值，项目是三相馈线峰值
Xin > 0 换流方向 + 电荷代理 + 残压 项目不用 Xin 解析式；用逐事件诊断
fr < fs < fmax 210–340 kHz 搜索窗 + 最终 241.59–299.26 kHz 项目窗口是研究设置，不是硬件边界
Fnmin = min{...} 离散搜索 + 表格 项目不实现式 (20)；不能把式 (20) 写成项目控制律

5 常见公式错误

  1. 把式 (11) 当通用式：它只对 k = 0.213 的样机参数拟合；换 Cp/Cr、Lr、fr 必须重推。
  2. 把 Io = Im(1−cosθ)/(nπ) 当成恒流关系：θ 随 M、Fn 变，Io 不是 Im 的常数倍。
  3. 把 Xin > 0 当 ZVS 认证：它只是输入阻抗感性；实际 ZVS 还要看死区电荷、Coss、门极时序。
  4. 把式 (20) 当“保证全部约束”：外层 min 只是截断；下界超上限时无解。
  5. 把 t800 与 T20→800 混用：前者含 0→20 V 启动，后者不含；差约 65 μs。
  6. 把准静态积分当动态结果：Co∫dV/Io 是估算；启动、频率切换、停充尾流要时域模型。
  7. 把 M1 的 2.153487 ms 与 M2 的 2.572428 ms 并列：模型层级不同，不能直接比较。
  8. 把 14 A 当器件额定：它是研究情景；最终表 13.99995 A 只是贴线。
