# 03 项目最终 AOC 轨迹：59 节点查表

> 这是本资料包的核心。它回答：本项目的“AOC”到底是什么、怎么算出来、最终表长什么样、结果是多少、哪些还没做。
> 对应文件：`data/aoc_59_nodes.csv`；对应验证：`docs/04_validation.md`。

---

## 1 对象与目标

### 1.1 主电路

```
Vin 50 V
  → 三相三桥臂逆变（S1/S4→A，S2/S5→B，S3/S6→C；120°）
  → 每相：Ls 4.7 μH → Cs 135 nF → Δ 接 Cp 27 nF/边
  → 三台单相变压器 1:4（一次 Δ / 二次 Y 浮空）
  → 共用六二极管桥（D1/D3/D5 上半桥，D2/D4/D6 下半桥）
  → Co = 6.25 μF × 2 串联 = 3.125 μF
  → Vo 0–800 V（储能增量 1 J）
```

| 量 | 值 |
|---|---:|
| `Vin` | 50 V |
| `Ls` / `Cs` | 4.7 μH / 135 nF |
| `Cp`（Δ 每边） | 27 nF |
| `n = Ns/Np` | 4 |
| `Co` | 3.125 μF |
| `Vo` 目标 | 800 V |
| 储能增量 | 1 J |
| 研究相峰值上限 | 14 A |
| 研究频率窗口 | 210–340 kHz |

### 1.2 为什么需要 AOC 型轨迹

三相 LCC 的输出电流 `Io` 不是 `fs` 的单调单值函数：随 `Vo` 升高，整流导通对、`Cp` 钳位形态、三管/两管区间都会变。固定频率无法在每个电压点都用满器件能力：

- 低压段用低频率可得到更大 `Io`，但相峰值接近 14 A；
- 高压段降频可能提高 `Io`，却破坏换流方向/电荷条件；
- 因此需要**逐电压点**在可行集合内选频，而不是一条全局单调的 `fs(Vo)` 直线。

AOC 的思想正好是“逐点最大化可行输出电流”。本项目把它离散化到 HOGA 冻结 `Vo` 的周期解上。

## 2 优化问题

```
fs*(Vo) = arg max  Io(Vo, fs)                         (1)
          fs ∈ F(Vo)

F(Vo) = { fs :
    HOGA 物理守卫通过,
    阶数验收通过（H31/H63）,
    CCM 分支存在,
    max_j |io_j| ≤ 14 A,
    min_ℓ i_comm,ℓ ≥ 1.40019 A,
    210 kHz ≤ fs ≤ 340 kHz }                           (2)
```

### 2.1 各项约束的来源

| 约束 | 来源 | 性质 | 不能写成 |
|---|---|---|---|
| HOGA 守卫 | 电流零和、`Cp` 钳位残差、能量闭合、二极管反向电流等 | 数值/物理必要条件 | “硬件安全” |
| 阶数验收 | H31/H63 谱残差、周期闭合、事件结构等 | 数值精度门槛 | “模型无误” |
| CCM | 选定导通分支 | 模型适用域 | “DCM 不存在” |
| 14 A | 研究情景 | 统一比较标尺 | “器件额定/热限额” |
| 1.40019 A | `Qreq/teff` | 必要能力代理 | “ZVS 认证” |
| 210–340 kHz | 搜索窗口 | 研究设置 | “硬件允许范围” |

> **版本说明**：AOC 搜索沿用 **V2.2 研究快照**（与旧 AOC 同方程），没有切换到来源 V2.3。本文中的“HOGA”指该快照；不要写成“用 V2.3 求解”或“已升级到 V2.3”。V2.3 的方程/审计是另一条证据链。

### 2.2 换流代理的算法

```
Qreq = 2 × Qoss(50 V) = 2 × 55.505 nC = 111.010 nC
teff = 79.281831 ns        （100 ns 命令死区 − RC 门极有效延迟）
Icomm,min = Qreq / teff = 1.4001947 A
```

- `Qoss(50 V)` 来自 IPP70N10S3L-12 手册图 10 的 19 锚点分段线性积分；单管 55.505 nC、1.039904 μJ；
- 对称桥臂完整换流需要两只 MOS 的电荷，故乘 2；
- `teff` 由 0/10 V 门极命令、14.945 ns RC、2 V 阈值推得；
- 该代理只筛“电荷够不够”，不证明“开通前 `Vds` 到零”。

## 3 怎么得到 59 节点

### 3.1 搜索流程（按时间）

| 步骤 | 做什么 | 结果 |
|---|---|---|
| 1 | 复用既有 423 个通过守卫的 HOGA 点 | 基础网格 |
| 2 | 扩域 377 条、模态恢复 88 条、局部频率加密 261 条 | 含失败与不同验收层级的记录 |
| 3 | 线性频率插值检查 | 发现轻微 14 A 越界、模态/求解失败 → 放弃插值 |
| 4 | 改为 20 个独立电压区间，每区间固定频率；两端+中点三点核验 | 20 段实施表，准静态 2.184381 ms |
| 5 | 逐节点候选在 254 V 出现 251.064 kHz 尖峰 | 用 293 V 解作初值，恢复低频分支 |
| 6 | 215–293 V 改直线频率桥，每 1.95 V 检查，共 41 点 | 41 点全通过；最大相峰值 13.999485 A |
| 7 | 41 新点 + 18 保留节点 = 59 节点 | 最终表 `aoc_smooth254_59_nodes.csv` |

### 3.2 20 段实施表（中间产物）

- 每区间一个固定频率，先取相邻最优频率上包络的 100 Hz 取整，再按需小幅升频或回退 280/290/300 kHz；
- 每选中频率核验区间两端 + 中点，共 60 次（H63 48 次、H15 11 次、H31 1 次；其中 12 次复用原阶数验收）；
- 最大相峰值 13.999454 A，最小换流代理 1.453460 A；
- 准静态 20→800 V **2.184381 ms**（比旧窗口 2.544446 ms 快 14.151%）；
- 比逐节点候选保守约 4.095%。

> 20 段表是**保守实施参考**，不是最终验证轨迹。最终动态与 20 点验证用的是 59 节点表。两者不要混。

### 3.3 254 V 修订

原逐节点候选在 254 V 取 251.0643 kHz，曲线出现向上尖峰；原因是保留的 245/250 kHz 解未通过代数闭合（事件残差约 0.0237/0.00898），不是物理不可行。修订：

| 254 V 版本 | `fs` / kHz | `Io` / A | `Ipk` / A |
|---|---:|---:|---:|
| 原候选 | 251.0643 | 1.544274 | 12.536473 |
| 恢复分支后重新求优 | 243.894287 | 1.753569 | 13.999924 |
| 连续路径参考（最终采用） | 244.273450 | 1.740951 | 13.911246 |

直线桥：

```
fs(Vo) = 244614.9 + (243932.0 − 244614.9)·(Vo − 215)/78   [Hz]
```

- 适用 215 ≤ Vo ≤ 293 V；
- 41 个检查点全部通过 H31/H63、代数闭合、物理守卫、CCM、14 A、换流代理；
- 254 V 处 `Io` 比原候选提高 12.7359%；
- 该段最大相峰值 13.999485 A、最小换流代理 9.853760 A；
- 采样通过不等于连续域证明。

### 3.4 最终表的构成

| 来源 | 节点数 | 说明 |
|---|---:|---|
| 215–293 V 新增局部点 | 41 | 每 1.95 V 一个 |
| 其他保留原节点 | 18 | 20/59/98/137/176/332/371/410/449/488/527/566/605/644/683/722/761/800 V |
| **合计** | **59** | 加 0–20 V 的 300 kHz 启动段，共 61 个查表断点 |

## 4 最终表长什么样

### 4.1 关键统计

| 量 | 值 |
|---|---:|
| 节点数 | 59 |
| 频率范围 | **241.5905–299.2573 kHz** |
| 相峰值最大 | **13.99995 A**（59 V 节点；距 14 A 仅 0.00005 A，属贴线） |
| 换流代理最小 | **1.43999 A**（683 V 节点；阈值 1.40019 A，余量约 2.8%） |
| `Io` 范围 | 1.85547 A（20 V）→ 0.79996 A（800 V） |
| 准静态 20→800 V | **2.089438 ms** |
| 0–20 V 启动 | 300 kHz，约 65.456 μs（M2 诊断值） |
| 动态 `t800`（M1） | **2.153487 ms** |

### 4.2 轨迹形态（写作重点）

| 区段 | 行为 | 原因 |
|---|---|---|
| 0–20 V | 300 kHz 固定 | 零压启动，不把主段模型用于 `Vo≈0` |
| 20–215 V | 约 243.6–244.6 kHz，几乎平台 | 低压段电流受限，低频率换大 `Io`；相峰值贴 14 A |
| 215–293 V | 244.61→243.93 kHz 缓降 | 254 V 修订后的直线桥；避免尖峰 |
| 293–371 V | 243.9→241.59 kHz | 全表最低频点在 371 V；仍受电流/换流约束 |
| 371–410 V | **跳变** 241.59→272.27 kHz | 模态/整流分支切换；不能画成连续升频 |
| 410–527 V | 272→280 kHz | 高压段逐步升频 |
| 527–566 V | 280.0→279.0 kHz（轻微回落） | 非单调；保留实际记录，不人为平滑 |
| 566–800 V | 279→299.26 kHz | 接近频率上限，相峰值回升到 13.55 A |

> **不要画成一条单调光滑曲线。** 最终轨迹是“低频率大电流 + 371 V 最低点 + 410 V 分支跳变 + 高压升频”的分段形态。非单调不是错误，是三相模态/整流事件造成的。

## 5 控制实现

### 5.1 结构

```
Vo → 1-D 查表（61 断点，Flat）→ fs
   → ×2π → 相位积分器 θ
   → sin(θ), sin(θ−120°), sin(θ−240°)
   → 门极掩码（M1 为零死区；M2 另加 100 ns 命令死区）
   → 六路驱动
```

- 三相共用同一个相位积分器，频率切换时相位连续；
- 查表区间内**不插值**（Flat），保留检查过的分支；
- 到 800 V：`q[k+1] = q[k] OR (Vo[k] ≥ 800)`，锁存后封锁六路驱动；
- 锁存后模型继续求解，保留残余能量与过冲；没有自动重启。

### 5.2 它不是什么

| 容易误解 | 实际 |
|---|---|
| “实现了 AOC 在线控制器” | 只是离线 `fs(Vo)` 前馈表；没有 `Iref` 在线求解 |
| “有电流 PI” | 没有；`Iref` 只作为表内记录，不进入闭环 |
| “有 ZVS 闭环保护” | 没有；14 A/换流代理只在离线筛选时用 |
| “有 800 V 恒压/Burst” | 没有；只有锁存停充 |
| “频率连续可调” | 查表是阶梯；215–293 V 表内点较密，但仍是离散 |

### 5.3 动态模型的实际设置

| 项 | 值 |
|---|---|
| 模型 | `AOC_charge.slx`（`ideal_three_phase_LCC` 副本） |
| 求解器 | ode15s，RelTol 2e-7、AbsTol 2e-9 |
| MaxStep | `1/(200·299257)` s |
| StopTime | 3.5 ms |
| 器件 | `Ron = 1e-6 Ω`、`Vf = 0.6 V`、`Goff = 1e-11 S`、`td = 0`、`Coss = 0` |
| 死区 | **0**（该模型）；100 ns 只在器件近似模型里 |
| 结果 | `t800 = 2.153487 ms`；3.5 ms 末值 800.112 V |
| 完全理想器件 | `t800 = 2.151012 ms` |

> 这就是 M1 层。它比 M2（100 ns + Coss + Cj）轻，不能拿它的 `t800` 与 M2 的 2.572428 ms 比。

## 6 结果

### 6.1 准静态

```
T20→800 = 2.089438 ms
t20     = 0.065456 ms（M2 共同启动诊断值，仅作量级核对）
合计    ≈ 2.154894 ms
```

与 M1 动态 `t800 = 2.153487 ms` 相差约 **0.065%**，说明“逐点冻结 + 电压域积分”在该轨迹上与动态结果量级自洽。注意：`t20` 取的是 M2 的诊断值，不是 M1 的严格同层启动时间，因此这只是量级核对，不是严格误差预算。

### 6.2 动态（M1）

| 表 | `t800` / ms | 相对旧表 |
|---|---:|---:|
| 旧 21 节点 280–299 kHz | 2.596206 | — |
| **最终 59 节点** | **2.153487** | **−17.05%** |
| 最终 59 节点（M0 全理想） | 2.151012 | −17.15% |

- 这是**同模型、同口径**的对比；
- 不能写成“相对 HCC–CP 提高 17.05%”；
- 不能与文献 1.82/1.62 s 比“快多少倍”。

### 6.3 20 点模型精度

见 [`04_validation.md`](04_validation.md)。摘要：

| 指标 MAPE | HOGA-H49 | EDF | FHA |
|---|---:|---:|---:|
| RMS | 0.00391% | 0.391% | 13.027% |
| `Io` | 0.00566% | 0.349% | 10.921% |
| 峰值 | 0.0270% | 1.573% | 13.784% |
| NRMSE | 0.0307% | 2.138% | 23.851% |

> 这是**模型精度**，不是控制精度，也不是硬件精度。

## 7 与旧版/中间版的量化关系

| 版本 | 频率范围 | 节点/区间 | 准静态 20→800 V | M1 动态 | 状态 |
|---|---|---|---:|---:|---|
| 旧 21 节点 | 280–299 kHz | 21 节点 | 2.544446 ms | 2.596206 ms | 历史对照 |
| 20 段实施表 | 243.7–299.3 kHz | 20 区间 | 2.184381 ms | 未跑 | 中间保守参考 |
| 逐节点候选 | 241.59–299.26 kHz | 21 节点（254 V 前） | 2.098458 ms | 未跑 | 中间候选 |
| **最终 59 节点** | **241.59–299.26 kHz** | **59 节点** | **2.089438 ms** | **2.153487 ms** | **最终** |

- 旧→新准静态：`1 − 2.089438/2.544446 = 17.882%`；
- 旧→新动态：`1 − 2.153487/2.596206 = 17.053%`；
- 20 段→逐节点候选：`1 − 2.098458/2.184381 = 3.935%`（报告写“约 4.095%”，是反向 `1 − 2.184381/2.098458` 的分段代价口径）；
- 20 段→59 节点：`1 − 2.089438/2.184381 = 4.347%`（不同对照，不能与 4.095% 直接混用）。

> 只在同一列内比较；不要跨列构造“总提升”。

## 8 最终版仍然缺什么

| 缺口 | 现状 | 影响 |
|---|---|---|
| M2 全程 | 59 节点表没有在 100 ns + Coss + Cj 模型跑过 | 不能写“最终轨迹通过器件约束” |
| 800 V 末端共同可行 | M2 下 7 个离散频点无同时满足 14 A 与残压者 | 不能写“末端可行”；290–295 kHz 未连续精查 |
| 14 A 依据 | 研究情景 | 不能写“器件安全/热限额” |
| 1.40019 A 代理 | `Qreq/teff` | 不能写“ZVS 已实现” |
| 连续域证明 | 离散 HOGA + 局部加密 | 不能写“全局最优/连续域无解” |
| 闭环 | 开环查表 | 不能写“AOC 控制器/电流 PI” |
| 损耗/温升 | 未对最终表积分 | 不能写“效率提升/温升降低” |
| 硬件 | 无 | 不能写“实验验证” |
| 参数鲁棒性 | 无最终表的 ±Cp/±Cs 扫描 | 不能写“工程鲁棒” |

## 9 写作时建议的“一句话定位”

> 本文不重新提出 AOC 方法，而是把 Qin 等“逐电压点最大化可行输出电流”的思想离散化到三相 Δ/Y LCC 的 HOGA 周期模型上，构造一条 59 节点的离线 `fs(Vo)` 查表轨迹；该轨迹在 14 A 相峰值情景、HOGA 守卫/阶数/CCM、换流电荷代理与 210–340 kHz 窗口内逐点筛选，并用冻结 `Vo` 的 20 点 Simulink 参考验证了模型精度。它是开环前馈轨迹，不是原论文的在线电流闭环，也未经过器件近似模型的全程验收或硬件实验。
